📖 Google Drive Setup Guide (5 min)
  1. Go to console.cloud.google.com
  2. Click Create Project → name it "Life School Camps" → Create
  3. Go to APIs & Services → Library
  4. Search "Google Drive API" → Enable it
  5. Go to APIs & Services → Credentials
  6. Click Create Credentials → OAuth client ID
  7. Application type: Web application
  8. Under "Authorised JavaScript origins" add: null (for local files) and your domain if you host it
  9. Click Create → copy the Client ID
  10. Paste it in the box above → click Sign In
  11. Sign in with your Google account → done!
⚠️ Important: In the OAuth consent screen, add your Gmail as a "Test user" so you can use it before publishing.
